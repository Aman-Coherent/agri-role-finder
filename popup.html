Agri Role Finder

Every search asks Google about "Companies per search" companies at once, in one structured question - fewer searches for the same list, which is both faster and lower-risk (fewer requests from your IP). If a search comes back with no answer at all it is reloaded once. A company that still gets no answer goes back in the queue once, with different companies, before it is recorded as not found. If several searches in a row get no answer at all, the run pauses so you can check.
CAPTCHA: the run pauses and the tab comes to the front. Solve it there and the run continues by itself. If it isn't solved within 10 minutes those companies are marked blocked; Resume searches them again. If Chrome restarts mid-run, the run pauses - click Resume.
Concurrent tabs run that many batches at the same time, so 4 tabs × 3 companies per search works through 12 companies per round instead of 3. The tabs open in the background in your current window and are never brought to the front, so the run doesn't interrupt what you're doing - and it keeps working while the window is minimised or you're in another app. They close themselves when you press Stop.
Shorter delays and more concurrent tabs = faster, but both raise the chance of tripping a block (more tabs = more simultaneous traffic from one IP), and of reaching Google's limit for AI answers. 1-2 tabs is recommended; a run is staggered so the tabs don't all hit Google on the same instant. Concurrency can only be changed while the project is stopped.
